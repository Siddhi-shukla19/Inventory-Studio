# 📦 StockNest — Inventory Dashboard

StockNest is a responsive web application for managing products, tracking inventory value, and viewing product categories.

## ✨ Features
- Add and remove products
- Search and filter products
- View inventory statistics
- Category-wise product summary
- Tax and discount calculator
- Responsive design for mobile and desktop

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Download or clone the project.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in your browser.

## 📌 Note
Product data is stored temporarily and resets when the page is refreshed.
